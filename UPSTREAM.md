## CodeIgniter 4 — `user_guide_src/source/installation/running.rst`

**Where:** `codeigniter4/CodeIgniter4`, the "Running Your App" page, after the
"Worker Mode with FrankenPHP" section (which today is the only
application-server alternative to Apache/nginx the guide names).

**Why:** CI4 runs unmodified on ePHPm in per-request mode (recipe
`apps/codeigniter4`, tested on 4.7.5). ePHPm replaces the web server + PHP-FPM
pair with one binary; worker mode is deliberately *not* claimed, since CI4's
worker entrypoint is FrankenPHP-specific.

**Proposed text (reStructuredText):**

```rst
*******************
Hosting with ePHPm
*******************

`ePHPm <https://github.com/ephpm/ephpm>`_ is a single-binary PHP application
server that embeds the PHP runtime, so a CodeIgniter app needs neither a web
server nor PHP-FPM in front of it. Point its document root at **public/** and
give it the same rewrite rule as **public/.htaccess**:

.. code-block:: toml

    # ephpm.toml
    [server]
    listen = "0.0.0.0:8080"
    document_root = "/var/www/myapp/public"
    fallback = ["$uri", "$uri/", "/index.php?$query_string"]

.. code-block:: console

    ephpm serve --config ephpm.toml

``spark`` runs on the embedded interpreter with ``ephpm php spark migrate``.
A ready-to-run Docker recipe (with MariaDB, and a single-container variant on
ePHPm's embedded database) is maintained at
`github.com/ephpm/recipes <https://github.com/ephpm/recipes/tree/main/apps/codeigniter4>`_.

.. note:: ePHPm has its own persistent worker mode, but the worker entry
    point generated by ``php spark worker:install`` is specific to FrankenPHP
    and does not run on it; use ePHPm's default per-request mode.
```
